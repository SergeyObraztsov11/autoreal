# Автореал — дизайн-система

Статус: утверждена (сентябрь 2026).  
Стек UI: Tailwind + Fonts + Icon + Motion (без Ant Design).

## Идея

Дизайн выведен из логотипа: жёлтый `#FCE700` + чёрный + белый, тяжёлый курсив
с наклоном ~12°, чёрная обводка и «выдавленная» тень вправо-вниз.
Референс компоновки — геометрические лендинги: светлый фон, крупные
диагональные плашки, фото-прямоугольники на сдвинутых жёлто-чёрных пластинах,
плитки-иконки, заголовок
обычного начертания с жирными акцентными словами.

## Логотип

- `public/autoreal_logo.png` — основной (хедер ≥ md, футер, строка под hero)
- `public/autoreal_logo_small.png` — компактный (хедер < md)

## Токены (`app/assets/css/tokens.css` → `@theme`)

Цвета в теме Tailwind: в шаблонах `bg-yellow`, `text-ink`, `border-line`.
В CSS-классах системы — `var(--color-ink)`.

| Утилита        | Hex       | Роль                                    |
| -------------- | --------- | --------------------------------------- |
| `yellow`       | `#FCE700` | Плашки, CTA, акценты                    |
| `yellow-deep`  | `#E6D100` | Hover жёлтых кнопок                     |
| `ink`          | `#0A0A0A` | Текст, рамки, тени, тёмные секции       |
| `ink-2`        | `#1C1C1C` | Второй слой на чёрном (шеврон)          |
| `muted`        | `#5F5F5F` | Вторичный текст                         |
| `canvas`       | `#F4F4F2` | Фон страницы                            |
| `line`         | `#E2E2DF` | Тонкие разделители                      |
| `--g-skew`     | `-12deg`  | Наклон плашек под словами               |
| `shadow-hard*` |           | Жёсткая тень 3/4/5px, чёрная или жёлтая |

## Классы системы

| Класс                                    | Назначение                                                                                                                                    |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `g-h` + `<b>`                            | Заголовок; `<b>` — жирный курсив на скошенной жёлтой плашке. `on-dark` — жёлтый текст без плашки; `on-yellow` — жёлтый текст на чёрной плашке |
| `g-btn` + `g-btn-primary / ghost / dark` | Кнопки с чёрной рамкой 2px и жёсткой тенью 4px                                                                                                |
| `g-card`                                 | Белая карточка, рамка 2px, тень 5px                                                                                                           |
| `g-tile`, `g-tile-yellow`                | Плитка-иконка (чёрная/жёлтая)                                                                                                                 |
| `g-label`                                | Подпись секции (uppercase)                                                                                                                    |
| `g-para*`, `g-chevron`, `g-tri-*`        | clip-path формы с единым наклоном                                                                                                             |
| `g-hard`, `g-hard-sm`                    | Жёсткая чёрная тень                                                                                                                           |
| `g-input`                                | Поле формы                                                                                                                                    |
| `phone`                                  | Табличные цифры, без переноса                                                                                                                 |

## Правила

1. Жёлтая плашка всегда с чёрной подложкой-«выдавливанием» (сдвиг 12px).
2. Фото — прямоугольник на сдвинутых жёлтой + чёрной пластинах (`SectionPhoto`),
   `alt=""` для декоративных.
3. Иконки только в плитках карточек и плашках; без «рассыпанных» иконок рядом с текстом.
4. Ссылки — hover underline жёлтым (3px), не смена цвета.
5. Угловые фигуры (`g-tri-*`, квадраты) — 1–2 на секцию, не больше.

## Главная — секции

1. Hero — оффер, trust chips, запись / услуги
2. Why — гарантия, склад, запись, режим
3. Services — сетка услуг + акцент АКПП
4. Store — магазин
5. Contacts — два адреса
6. CTA — финальная запись
